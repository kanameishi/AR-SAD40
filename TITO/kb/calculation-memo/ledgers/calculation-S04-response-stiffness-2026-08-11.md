# Section

Resultantes seccionales y rigidez circunferencial.

# Report Purpose

Resolver $N_\theta(\theta)$, $M_\theta(\theta)$ y $Q_\theta(\theta)$ para
acciones autoequilibradas e introducir el perfil corrugado mediante sus
rigideces en la dirección circunferencial.

# Sources Read

Baker (1968); NCSPA (2018); documento metodológico aprobado.

# Exact Claims Allowed

El sistema diferencial expresa equilibrio. Tres constantes se fijan mediante
compatibilidad. En el problema plano, $EA_\theta$ y $EI_\theta$ son suficientes
para la ley seccional adoptada.

# Claims Not Allowed

No presentar una teoría general ortótropa, una corrección posterior de una
solución isótropa ni tensiones locales de la corrugación.

# Equations Allowed

Equilibrio global, sistema de primer orden, solución general, constantes de
compatibilidad, soluciones cerradas y $\eta_s=I_p/(A_pR^2)$.

# Equations Excluded

Matrices tridimensionales de lámina y acciones longitudinales.

# Vocabulary Allowed

Integración directa; compatibilidad; rigidez extensional; rigidez flexional;
perfil corrugado; resultante circunferencial.

# Vocabulary Rejected

Ecuaciones del anillo; clase ortótropa; corrección ortótropa; motor de cálculo.

# Candidate Public Paragraph Or Section

Algoritmo de integración y soluciones cerradas para control.

# Candidate Translation Terminology

`extensional rigidity` → rigidez extensional; `flexural rigidity` → rigidez
flexional.

# Open Gaps

Radio centroidal, categoría de espesor, $A_p$, $I_p$ y $E_\theta$ confirmados.
