# Section

Aplicación numérica y resultados.

# Report Purpose

Mostrar una ejecución completa y reproducible del estado biaxial uniforme con
dos prescripciones de carga.

# Sources Read

NCSPA (2018); documento metodológico aprobado; resultados numéricos auditados.

# Exact Claims Allowed

El diámetro 2.63 m y el perfil 76×25×3 mm son parámetros nominales. El radio,
las propiedades interpoladas y el estado de tensión adoptado forman un
escenario condicionado. Los resultados son derivados en este estudio.

# Claims Not Allowed

No presentar el escenario como demanda final; no confirmar el espesor base ni
el radio centroidal; no informar cuantiles o etapa gobernante.

# Equations Allowed

Estado biaxial, cargas perimetrales, propiedades seccionales y soluciones
cerradas de control.

# Equations Excluded

Tensiones y comprobaciones resistentes.

# Vocabulary Allowed

Escenario analítico; parámetro nominal; hipótesis adoptada; resultado derivado;
control matemático interno.

# Vocabulary Rejected

Caso real; valor medido; demanda de diseño; validación.

# Candidate Public Paragraph Or Section

Tabla de entradas, diagramas paramétricos, tabla de extremos y comparación con
la integración directa.

# Candidate Translation Terminology

`full tensor projection` → proyección completa del estado biaxial; `normal
only` → carga exclusivamente normal.

# Open Gaps
