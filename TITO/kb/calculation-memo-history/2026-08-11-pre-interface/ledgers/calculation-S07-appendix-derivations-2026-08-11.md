# Sources Read

Baker (1968); McGrath et al. (1999); NCSPA (2018); Efron (1979, 1987);
Wilson (1927); documento metodológico aprobado.

# Exact Claims Allowed

Derivación breve de equilibrio, solución homogénea, compatibilidad, perfil
corrugado y estimadores. La extensión a carga tangencial se identifica como
desarrollo de este estudio.

# Claims Not Allowed

No reproducir el capítulo metodológico completo ni introducir ramas nuevas.

# Equations Allowed

Ecuaciones intermedias indispensables para llegar a las fórmulas del cuerpo.

# Equations Excluded

Desarrollos de Schwartz--Einstein y Núñez que no intervienen en el cálculo
operativo de esta memoria; se resumen sólo como antecedentes de contraste.

# Vocabulary Allowed

Desarrollo; compatibilidad; periodicidad; coeficiente modal; estimador.

# Vocabulary Rejected

Prueba definitiva; demostración exhaustiva; solución canónica.

Monte Carlo.

homogénea.
