Source inventory of the adopted IND implementation by tectonic region type (TRT): SIS, Subduction Intraslab; SIF, Subduction Interface; SCC, Stable Continental Crust; ASC, Active Shallow Crust. Columns `Area` and `Point` give the number of area sources (`areaSource`) and point sources (`pointSource`); `Total` sums both. The complete model comprises 443,197 sources: 108 area sources and 443,089 point sources distributed over two smoothed-seismicity grids.
