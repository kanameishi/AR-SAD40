Structure of the IND source-model logic tree (27 end-branches, $3 \times 3 \times 3$). Branch set 1 selects the source model: `b1m1` adopts the 108-zone areal model (`nt2012_areal_source_model_v1.xml`); `b1m2` and `b1m3` adopt the smoothed-seismicity point-source grids with $M_{\min}$ thresholds of 4.5 and 5.5 (`nt2012_smoothed_source_model_v1_mmin4.5.xml` and `nt2012_smoothed_source_model_v1_mmin5.5.xml`). Branch set 2 perturbs the maximum magnitude of all sources by $\pm 0.3$; branch set 3 perturbs the Gutenberg–Richter $b$ value of all sources by $\mp 0.1$. Each branch carries its weight in parentheses; the weights sum to unity within each set.
