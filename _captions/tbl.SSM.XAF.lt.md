Structure of the XAF source-model logic tree (`ssmLT_XAF.xml`; 162 end-branches, $2 \times 3 \times 3 \times 3 \times 3$). Branch set 1 selects the source representation for all sources: `naf_faults` combines the explicit fault sources (`FaultSources.xml`) with the collapsed multi-point grids (`GridMultiSources_C_L50_BG.xml` and the collapsed WAF and SSA files); `naf_smooth` replaces the explicit faults with a purely smoothed-seismicity representation (`GridMultiSources_C.xml` with the same collapsed regional files). Branch sets 2 and 5 perturb the maximum magnitude by $\pm 0.2$ for the WAF multi-point sources (MPS-1 to MPS-6) and the NAF smoothed-seismicity sources (SC_1 to SC_54), respectively; branch sets 3 and 4 perturb the Gutenberg–Richter $b$ value by $\pm 0.05$ for the same groups. Each branch carries its weight in parentheses; the weights sum to unity within each set.
